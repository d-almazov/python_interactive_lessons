# Python-практикум

Інтерактивний практикум з Python для студентів: умовні оператори, цикли `for` і `while`, обробка винятків `try / except`. Теорія з прикладами, які можна запускати, і 14 станцій-завдань з анімаціями: теплиця, перехрестя, палетизатор, конвеєри, лабіринт, марсохід, датчики, верстат і фінальний міні-завод.

Код студента виконується просто в браузері через [Skulpt](https://skulpt.org) (Python 3, скомпільований у JavaScript). Сервер не потрібен: це статичний сайт.


## Як запустити локально

Достатньо відкрити `index.html` у браузері. Якщо браузер блокує локальні скрипти, запусти простий сервер з кореня репозиторію:

```bash
python -m http.server 8000
```

і відкрий <http://localhost:8000>.

## Структура

```
index.html            сторінка: розмітка і підключення скриптів
css/style.css         стилі, кольорові токени для світлої й темної теми
js/core.js            рівні, генерація сценаріїв, перевірка, запуск Python
js/scenes.js          анімації станцій (canvas)
js/ui.js              теорія, навігація, редактор коду, зірки
vendor/skulpt/        Python-рушій Skulpt 1.2.0 (ліцензія MIT)
tests/test_levels.js  перевірка, що еталонні розв'язки проходять усі сценарії
```

## Як додати або змінити станцію

Усі станції описані в масиві `LEVELS` у `js/core.js`. Кожна має:

- `title`, `brief`, `task`, `api`, `hints` — тексти для студента;
- `starter` — заготовка коду, `solution` — еталонний розв'язок;
- `gen(r, i)` — генератор сценарію `i` (`r` — генератор випадкових чисел із зерном);
- `world` — модель обладнання, `prelude` — Python-API, яке бачить студент;
- `check` — перевірка результату;
- `scene` — яка анімація з `js/scenes.js` її показує.

Після змін запусти тести:

```bash
node tests/test_levels.js
```

Ті самі тести автоматично запускаються на GitHub при кожному push (`.github/workflows/test.yml`).

## Прогрес студентів

Зірки й код зберігаються в `localStorage` браузера студента. Між пристроями прогрес не переноситься, і викладач його не бачить.
